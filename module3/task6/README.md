## Групповой UDP-чат с широковещательной рассылкой

Реализация задания №6 на C для Linux. Каждый экземпляр программы является равноправным клиентом: отдельного сервера нет.

- Имя участника задаётся при запуске.
- Сообщения отправляются по UDP на широковещательный адрес `255.255.255.255`.
- Типы пакетов: `JOIN`, `CHAT`, `HEARTBEAT`, `LEAVE`.
- При штатном выходе отправляется `LEAVE`.
- Для обнаружения аварийного завершения каждый клиент отправляет `HEARTBEAT` раз в секунду.
- Если от участника нет сообщений активности более 5 секунд, он удаляется из локального списка.

## Сборка

```bash
make
```

Или:

```bash
./run.sh Alex
```

## Локальный запуск

Откройте несколько терминалов в каталоге проекта и запустите по одному клиенту в каждом:

```bash
./udp_chat Alex
./udp_chat Bob
./udp_chat Charlie
```

По умолчанию используется UDP-порт `45454`. Можно задать другой порт последним аргументом:

```bash
./udp_chat Alex 45555
./udp_chat Bob 45555
```

Все участники одного чата должны использовать одинаковый порт.

Команды внутри чата:

- `/users` — показать известных участников;
- `/help` — показать справку;
- `/quit` — штатно выйти из чата.

Ctrl+C также приводит к отправке `LEAVE`, если процесс успевает обработать сигнал. При `SIGKILL` отправить уведомление невозможно, поэтому остальные клиенты обнаружат исчезновение по таймауту.

## Тестирование

```bash
make test
```

или:

```bash
./test.sh
```

Сначала запускаются модульные тесты протокола и таблицы участников. Затем интеграционный тест запускает локальных клиентов и проверяет `JOIN`, доставку `CHAT`, штатный `LEAVE` и обнаружение аварийного завершения по таймауту.
